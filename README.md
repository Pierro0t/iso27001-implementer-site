# ISO 27001 Implementer website

Static marketing and legal site for the **ISO 27001 Implementer** iOS/Android
app. Hosted on GitHub Pages.

- **Live**: https://pierro0t.github.io/iso27001-implementer-site/
- **Stack**: plain HTML/CSS/JS, no build step. Bilingual EN/FR (client-side
  toggle, preference stored in `localStorage`).

## Pages

| File | Purpose |
|------|---------|
| `index.html` | Landing page |
| `privacy.html` | Privacy Policy (Apple + Google required) |
| `terms.html` | Terms of Use |
| `support.html` | Support & contact URL (Apple + Google required) |
| `legal.html` | Legal notice / mentions légales |

## Deploy

GitHub Pages serves the repository root on the `main` branch. `.nojekyll` keeps
the files served as-is. To update, edit and push to `main`.
